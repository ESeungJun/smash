## 2026-11-01 Tauri 대신 Electron

- 정한 것: 앱 틀은 Electron, 화면은 프레임워크 없는 순수 JS.
- 후보: Tauri / Electron.
- 고른 이유: 개발 기기가 Intel Mac이고 Rust가 깔려 있지 않았다. Electron이면 앱 실행 파일을 `ELECTRON_RUN_AS_NODE=1`로 돌려 MCP 서버를 띄울 수 있어서 사용자가 Node를 따로 안 깔아도 된다.
- 누가 정했나: 이승준.
- 버린 시도: Tauri는 "다음 기회에"로 미뤘다.
- 근거: 개발 글 2장("이 맥에 Rust가 안 깔려 있어서 Tauri는 다음 기회에"), 프로젝트 메모리, 로컬 히스토리 `78849c0`.

## 2026-11-06 폴더 연결은 "묶음 + 기준 폴더", 한 단계만

- 정한 것: 폴더에 `link`(기준 폴더 id)를 둔다. 연결된 폴더는 자기 규칙 다음에 기준 폴더 규칙을 이어서 쓰고, 목적지는 기준 폴더 기준이다. 기본 설정에서 다운로드는 문서에 연결한다. 기준 폴더를 다시 다른 폴더에 연결할 수는 없다.
- 후보: 묶음 + 기준 폴더, 모든 대상이 규칙 공유, 규칙마다 적용 폴더 체크.
- 고른 이유: 다운로드·바탕화면 파일이 문서 폴더의 같은 분류 트리로 모이게 하면서도, 다운로드만의 규칙(오래된 설치 파일 휴지통)은 남길 수 있다. 연결을 한 단계로 묶어서 순환·연쇄를 따질 필요가 없다.
- 누가 정했나: 이승준(추천안 선택).
- 버린 시도: 스캔할 때 묶음의 모든 폴더를 한 번에 보여 주는 안. 자동 정리가 다운로드에 새 파일이 들어올 때 문서 폴더까지 건드리게 돼서 넣지 않았다. 같은 분류 트리를 공유하는 것으로 충분하다고 봤다.
