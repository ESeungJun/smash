# Smash! 기획서

> 이 문서는 2026-11-05에 이미 출시된 v1.1.0 코드·README·개발 글을 보고 거꾸로 정리했다. 구현된 기능을 사용자가 요구한 기능으로 보고 썼다.
> 함께 보기: [설계서](설계서.md) · [구현도](구현도.md) · [결정기록](결정기록.md)

## 한 줄 소개

내가 정한 규칙대로 다운로드·문서 폴더를 정리하는 Mac·Windows 앱. 정리하기를 누르면 화면에 커다란 손바닥이 내려와 "찰싹!!" 하고, 그 순간 파일이 제자리로 들어간다.

## 왜 만들었나

- 다운로드 폴더에 스크린샷, 설치 파일, 메신저로 받은 PDF, zip이 계속 쌓인다. 마음먹고 치워도 일주일이면 원래대로 돌아간다.
- 한 번 정한 규칙대로 알아서 치워 주면 된다. 다만 정리 앱은 이미 많아서, 한 번 더 누르고 싶게 재미를 얹기로 했다("방 좀 치워라!" 하며 등짝을 맞던 기억).
- 정리 앱은 파일을 한 번 날려 먹으면 다시 안 쓴다. 그래서 "맡겨도 불안하지 않게"를 가장 앞에 둔다.
- 근거: [dev-post 10-smash/post.md](https://velog.io/@haul/smash-downloads-folder-slap), [README.ko.md](../README.ko.md)

## 누가 쓰나

- 다운로드·문서 폴더가 늘 어지러운 Mac·Windows 사용자.
- Claude Code CLI에 이미 로그인해 둔 사람은 Claude 기능(규칙에 안 걸린 파일 자리 묻기, 말로 규칙 만들기, MCP로 정리 시키기)까지 쓴다. 로그인 안 해도 나머지 기능은 다 된다.

## 목표

개발 글의 목표 표를 그대로 옮긴다(dev-post `10-smash/tables/tables.html`).

| 목표 | 결정 | 이유 |
|---|---|---|
| 맡겨도 불안하지 않게 | 옮기기 전에 트리로 미리보기 | 파일이 어디로 가는지 모르면 정리 버튼을 못 누른다 |
| | 지우지 않고 휴지통으로만 | 잘못 옮겨도 되돌릴 수 있어야 손이 간다 |
| 내 PC의 Claude 그대로 | API 키 대신 `claude` CLI·MCP | 이미 로그인된 Claude가 있는데 키를 또 넣기 싫다 |
| | 파일 이름·크기·날짜만 보내기 | 다운로드 폴더엔 남에게 보이면 안 되는 파일이 섞여 있다 |
| 정리가 재밌게 | 정리하는 순간 등짝 스매시 | 한 번 더 누르고 싶게 |
| | 자동 정리는 잔소리 배너로 | 알아서 치운 것도 혼나면서 알게 되는 게 이 앱답다 |

## 핵심 시나리오

1. 앱을 연다. 다운로드와 문서 폴더가 정리 대상으로 이미 들어 있다.
2. 미리보기 탭에서 정리 뒤 폴더 모양을 트리로 본다. 새로 생길 폴더, 중복, 이름이 바뀌는 파일이 표시된다.
3. 그대로 둘 파일은 체크를 풀고 **짝! 정리하기**를 누른다.
4. 손바닥이 내리치는 순간(0.8초) 파일이 옮겨지고, 효과가 끝나면 파일이 들어간 폴더가 열린다.
5. 잘못 옮겼으면 기록 탭에서 그 정리를 골라 되돌린다.
6. 자동 정리를 켜 두면 새 파일이 다 받아진 뒤 알아서 정리하고, 화면 위쪽에 "으이구!! 폴더 청소 좀 하랬지!!" 배너가 내려온다.
7. Claude Code나 Claude Desktop에서 "다운로드 폴더 정리해 줘"라고 하면 앱과 같은 규칙·기록으로 정리한다.

## 기능 목록

### 구현됨 (v2.2.0)

| 영역 | 기능 |
|---|---|
| 정리 대상 | 폴더 여러 개 등록. 기본은 `~/Downloads`, `~/Documents`. 사이드바 폴더에 마우스를 올리면 나오는 ×로 목록에서 뺀다(두 번 눌러 확인, 파일은 그대로) |
| 하위 폴더까지 정리 | 폴더마다 체크(기본 꺼짐). 꺼져 있으면 사용자가 만든 하위 폴더는 건드리지 않는다. 켜면 하위 폴더 속 파일도 규칙대로 다시 정리하되, 앱·사진 보관함 같은 꾸러미 폴더와 개발 프로젝트(.git, package.json 등)는 들어가지 않는다 |
| 폴더 연결 | 폴더를 다른 폴더(기준 폴더)에 연결하면 자기 규칙 다음에 기준 폴더 규칙을 같이 쓴다. 다운로드·바탕화면 파일이 문서 폴더의 같은 분류 트리로 모인다. 기본값: 다운로드 → 문서 |
| 소분류 | 규칙마다 "그 폴더 안에서 한 번 더 나누기": 안 나눔 / 자동(용도·이름·시간) / 연·월. 자동은 이미 있는 하위 폴더 이름 → 용도 단어(영수증·계약서·스크린샷·카카오톡 …) → 카메라 사진(찍은 날짜별) → 이름 앞부분이 같은 파일 3개 이상 → 몇 시간 안에 몰린 사진·영상 순서로 묶는다 |
| 규칙 | 파일 종류 칩(사진·이미지, 동영상, 음악·녹음, 문서, 표·슬라이드, 압축, 설치 파일, 폰트·개발) 또는 확장자, 이름에 든 단어, "N일 지난" 조건. 할 일은 폴더로 옮기기 또는 휴지통 |
| 규칙 미리 맞춰 보기 | 규칙을 만드는 동안 지금 폴더에서 걸리는 파일 수를 바로 보여 준다 |
| 기본 규칙 | 문서 폴더: `사진·이미지`, `미디어`, `자료`, `개발리소스`(모두 자동 소분류). 다운로드: 7일 지난 설치 파일은 휴지통, 나머지는 문서 폴더 규칙을 같이 쓴다 |
| 미리보기 | 정리 뒤 폴더 트리, 새 폴더·중복·이름 변경 표시, 파일별 체크 |
| 등짝 스매시 | 투명 전체화면 창에 손바닥·"찰싹!!"·흔들림, 앱 창 들썩임. 마우스는 통과. 설정에서 끔 |
| 정리 뒤 폴더 열기 | 옮긴 자리들의 공통 상위 폴더를 연다. 설정에서 끔 |
| 자동 정리 | 폴더별로 켬. 파일 크기가 두 번 그대로이면 다 받아진 것으로 보고 정리. 창을 닫아도 트레이에서 계속 지켜봄 |
| 잔소리 배너 | 자동 정리 뒤 화면 위쪽 가운데 4.5초. 누르면 정리한 폴더를 연다 |
| 안전장치 | 영구 삭제 없음(휴지통만), 같은 이름은 ` (2)`, 내용까지 같으면 중복으로 휴지통, 숨김·다운로드 중 파일·폴더는 안 건드림, 설정한 폴더 밖으로는 안 옮김, 한글 NFD/NFC 맞춰 비교 |
| 기록·되돌리기 | 정리 기록 최근 50건(실행별 파일, 옮기기 전에 기록), 실행을 골라 되돌리기, 실패분 다시 시도, 휴지통 복원(macOS·Linux), 중단된 정리 복구 |
| Claude: 자리 묻기 | 규칙에 안 걸린 파일을 `claude -p`(도구 끔)에 물어본다. 이름·크기·날짜와 폴더 목록만 보낸다 |
| Claude: 말로 규칙 만들기 | "문서는 계약서·영수증·과제로 나누고 사진은 게임 스샷만 따로" 같은 문장으로 대분류·소분류 **규칙 세트**를 만든다. 지금 규칙·폴더·파일 종류(확장자 개수와 이름 표본)를 보고, 겹치는 규칙은 새로 만들지 않고 고침으로 낸다. 구체적인 규칙은 맨 위, 넓은 규칙은 맨 아래. 제안을 골라서 한 번에 저장 |
| Claude: 사진·영상 내용으로 묶기 | 설정에서 켜야만(기본 꺼짐) 미리보기에 버튼이 생긴다. 누르면 줄인 썸네일(긴 변 384px, 동영상은 한 장면)을 Claude에 보여 주고 "게임/엘든 링", "사진/음식"처럼 비슷한 것끼리 하위 폴더를 정한다. 한 번에 120개까지 |
| MCP 서버 | 이름 `smash`, 도구 7개(`list_targets`, `scan_folder`, `plan_moves`, `apply_plan`, `add_rule`, `undo_last`, `history`). 앱에서 Claude Code(모든 `CLAUDE_CONFIG_DIR` 위치)·Claude Desktop에 등록 |
| 언어 | 한국어·영어. 처음엔 시스템 언어, 설정에서 바꿈. 영어로 처음 만들면 기본 폴더 이름도 영어 |
| 버전·업데이트 | 설정 탭 맨 아래 앱 정보 카드(지금 버전, 업데이트 상태, 확인·설치 버튼, 릴리스 노트 링크). 트레이에 버전과 "업데이트 확인…". 새 버전은 저절로 받아 두고 한 번 알린다. 설치는 사용자가 눌러야 한다 |
| 창 닫기 | X를 누르면 맥·윈도우 모두 트레이(메뉴 막대·알림 영역)로 숨는다. 끝내기는 트레이 메뉴의 '종료'. 윈도우는 처음 숨길 때 알림으로 한 번 알린다 |
| 기타 | 로그인 시 실행, 트레이(메뉴 막대·알림 영역) 메뉴 |

### 나중

- Windows 코드 서명: 맥은 2.0.0부터 서명·공증했고, 윈도우는 아직 SmartScreen에서 "추가 정보 → 실행"을 눌러야 한다.
- Windows 실기기 테스트: README에 "실제 윈도우 기기에서는 아직 테스트하지 않았다"고 적혀 있다.

### 범위 밖

- 영구 삭제: 안전 원칙상 넣지 않는다.
- 파일 내용을 Claude에 보내기: 개인 파일이 섞여 있어 이름·크기·날짜만 보낸다. 예외는 사용자가 켠 '사진·영상 내용으로 묶기'의 줄인 썸네일뿐이고, 원본 파일은 보내지 않는다.
- 앱에 Claude API 키 넣기: 로그인된 CLI·MCP만 쓴다.
- 폴더 통째로 옮기기: 폴더(git 저장소 포함)는 건드리지 않는다.
- 폴더 통째로 다른 곳으로 옮기기·폴더 이름 바꾸기: 하위 폴더까지 정리를 켜도 파일만 옮긴다.
- 사진 속 사람 알아보기: 내용 묶기에서 누구인지 추측하지 않게 프롬프트로 막는다.
- Linux 배포판: 휴지통·설정 경로 코드는 있지만 빌드 스크립트와 설치 파일은 macOS·Windows만 있다.

## 완료·성공 기준

- 테스트(`npm test`) 전부 통과: 규칙 매칭, NFD 한글, 스캔(순서·중복·이름 충돌·건너뛰기), 옮기기→되돌리기, 덮어쓰지 않기, 정리 대상 밖 거부, 휴지통, Claude 응답 해석, MCP 서버, 자동 정리, 언어, 소분류, 하위 폴더·연결 스캔, 썸네일. 2026-11-10 기준 `cargo test` 57개(각 `src-tauri/src/*.rs`의 `#[cfg(test)]`. 도중 종료·동시 실행·심볼릭 링크 경계 포함)와 `node --test` 9개(`test/logic.test.js`).
- 설치한 앱을 30초 넘게 띄워 두고 크래시 리포트까지 확인한다(빌드 이름 문제로 8초 뒤 죽던 일 뒤로 정한 기준, [결정기록](결정기록.md)).
- 실제 다운로드 폴더의 실제 파일(한글 이름 스크린샷 포함)로 규칙이 걸리는지 확인한다.
- 정리 버튼을 누르면 효과보다 폴더 창이 먼저 뜨지 않는다.
- 사용자 수·다운로드 수 같은 지표는 근거 자료가 없어 적지 않는다.
